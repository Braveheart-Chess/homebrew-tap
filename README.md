# homebrew-tap

The Homebrew tap for [Braveheart](https://github.com/Braveheart-Chess/braveheart),
a UCI chess engine in Rust.

```sh
brew install braveheart-chess/tap/braveheart
```

The repository rules are in [CONTRIBUTING.md](CONTRIBUTING.md), and restated
for coding agents in [AGENTS.md](AGENTS.md).
